03　ルビの基本構造

親文字と読みの対応を比較する。語全体へのルビと、一文字ずつのルビを別の試験にする。折り返しと長いルビは第28章に収録。

参照：JLReq（日本語組版処理の要件） / CSS Ruby Level 1（草案） / HTML Standard: ruby。判定方法は第25章。

R03-G　グループルビ

判定区分：CSS。期待結果：「明日」全体に「あした」が対応し、読みが隣の語へずれない。

明日あした、宇宙そらへ。銀河鉄道ぎんがてつどうが走る。

R03-M　モノルビ

判定区分：CSS。期待結果：山に「やま」、川に「かわ」がそれぞれ対応する。

山やま川かわを越える。

R03-P　親文字ごとの対応を持つルビ

判定区分：CSS。期待結果：天に「てん」、体に「たい」、観に「かん」、測に「そく」が対応する。読みの配分を保つ。

天てん体たい観かん測そくを続ける。
