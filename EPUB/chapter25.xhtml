25　利用方法・判定基準

本テスト集は検証本文34章に表紙と奥付を加えた構成。第23章は挿絵の透明度・色・線・画素比率を比較する試験。第1〜24章は基本機能、第26〜33章は境界条件と実用上の回帰試験。第34章はフォント選択・継承・埋め込みの試験。v2の通常本文は書体未指定で、本文用の書体指定は第34章の試験段落に置き、コード表示の等幅と表紙・奥付の体裁は維持する。本文はオリジナルであり、規格の例文・図版を複製していない。

参照：JLReq（日本語組版処理の要件） / CSS Text Level 3。判定方法は第25章。

判定の区分

CSS：参照仕様の規則を確認する。仕様が許す差や、実装に委ねる改行位置は許容する。

組版方針：JLReqの組版上の目標や本書が選んだ体裁を確認する。結果だけからEPUB仕様違反とは判定しない。

対応状況・観察：高度なルビ、フォント、検索などの差を記録する。見た目の違いを直ちに不適合としない。

挿絵の表示：第23章は原画像を基準に比較し、背景色や画像補正の設定による変化を記録する。自動補正の有無や適用範囲を、リーダー共通の合否条件にはしない。

結果の記録

各ケースを「適合」「不適合」「機能未対応」「フォント不足」「条件未成立」「未実施」のいずれかで記録する。異なる原因がある場合は判定項目を分ける。

記録欄：ケースID／試験する規則／結果／リーダーと版／OS・ブラウザと版／実際に使用されたフォント／表示領域の寸法／文字サイズ／実効行間／縦横方向／ページ・スクロール方式／画像の保存先／備考。

文字幅や禁則のため対象文字が行端に来なかった場合は条件未成立とする。禁則により前の文字ごと移動した場合は、回避動作として評価する。単に三つの表示が同じという理由だけで未対応とはしない。

比較手順

  1. 初めにリーダーの方向設定を自動へ戻し、書籍指定の縦書きで開く。
  2. フォントの読み込み後、同じ本文・寸法の対照例と比較する。ラベルと説明は試験枠の外にある。
  3. 書籍CSSと実効CSSが異なる場合は、上書きされたプロパティを記録する。フォント候補名だけで実使用フォントを断定しない。
  4. 行末試験は前置き三字・四字・五字などの複数例を確認する。枠内に強制改行やnowrapを追加して結果を作らない。
  5. 第29章は通常と拡大文字、小画面と大画面、端末の縦横、単ページと見開きなど利用可能な条件で確認する。
  6. 前後のページへ移動し、再レイアウト前後に本文の欠落・重複・装飾の切れがないことを確認する。

比較時の注意

ページ数と改行位置は固定しない。第29章の段落IDを基準に読む位置を追う。ページ境界の試験で一ページに収まった場合は文字を拡大するか画面を縮める。

第30章の字下げや約物のアキには複数の組版慣行がある。第28章の熟語ルビと第14章の二重ルビには対応差がある。試験で採用した方針を記録する。

EPUBCheckはファイル構造を検証する。各ケースの表示や検索の正しさを保証するものではない。本書にはスクリプト・外部フォント・外部画像を含めない。第34章のための小さなフォントサブセットをEPUB内に収録し、通常本文には適用しない。
