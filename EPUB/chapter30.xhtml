30　約物のアキ・段落整形

約物の詰め方や字下げの慣行を比較する。各ケースの指定した体裁を評価し、すべての日本語文書に同じ体裁を要求しない。

参照：JLReq（日本語組版処理の要件） / CSS Text Level 3 / CSS Text Level 4（草案）。判定方法は第25章。

S30-P-space-all　約物のアキ / space-all

判定区分：組版方針・CSS草案の対応状況。期待結果：連続する括弧・句読点のアキを比較する。text-spacing-trim未対応は機能未対応とする。両方が同じ表示でも、文字が実際に対象位置へ来たかを先に確認する。

彼は「星」と言った。「月」とも書いた。『記録（第一）』を開くと、海・山・空が並んでいた。

S30-I-0　括弧で始まる段落 / 字下げ0

判定区分：組版方針。期待結果：指定した字下げで始まる。括弧の字面と文字の送り幅を区別し、採用する段落体裁を記録する。

「星の位置を記録する」と手帳に書いた。港の灯りは遠くに見えた。
