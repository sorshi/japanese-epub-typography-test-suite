英語部分はlangとxml:langの両方を指定する。自動の折り返しと、U+00A0による著者の明示指定を区別する。

参照：JLReq（日本語組版処理の要件） / CSS Text Level 3 / CSS Writing Modes Level 4。判定方法は第25章。

M31-WORD　和文と欧文単語

判定区分：CSS。期待結果：normal指定で短い欧文単語の内部を不要に分断しない。日本語との境界のアキは観察として記録する。

星をskyと記し、starを探す。

M31-NUM　数値・小数点・単位

判定区分：組版方針・観察。期待結果：1,234、12.5%、100kmの向きと分割位置を記録する。数値と単位の一体化は書籍の指定有無も合わせて判定する。

距離1,234メートル、割合12.5%、速度100km。

M31-NBSP　単位との分離を禁止する指定

判定区分：CSS。期待結果：12とkmの間のU+00A0では改行しない。通常の空白との対照を比較する。

距離12 km先。距離12 km先。
