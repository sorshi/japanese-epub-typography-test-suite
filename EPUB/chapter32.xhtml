32　圏点の対象・装飾の衝突

付ける対象と除外する対象、左右位置、ルビとの共存を独立して評価する。

参照：CSS Text Decoration Level 3 / CSS Ruby Level 1（草案） / CSS Writing Modes Level 4。判定方法は第25章。

E32-SKIP　句読点・括弧・空白

判定区分：CSS。期待結果：天・地・玄・黄の四文字に圏点が付き、この例の句読点・括弧・半角空白・全角空白には付かない。

天、地。「玄」 黄　

E32-SYMBOL　記号の例外

判定区分：CSS。期待結果：この例の#・%・&には圏点を付ける。すべての記号を一律に除外する判定をしない。

星#月%海&

E32-right　圏点の位置 / right

判定区分：CSS。期待結果：縦書きの右側に圏点が付き、字面と重ならない。

E32-left　圏点の位置 / left

判定区分：CSS。期待結果：縦書きの左側に圏点が付き、字面と重ならない。

天体観測

E32-RUBY　ルビと圏点・通常行間

判定区分：CSS。期待結果：親文字の右ルビと左圏点を識別でき、読みには圏点を継承させない。親文字・隣接行が欠けない。

E32-COLLIDE　同じ側のルビと圏点

判定区分：装飾のストレス・観察。期待結果：同じ右側へ配置したルビと圏点の距離・重なりを記録する。固定の狭い行間が原因の衝突は通常行間の結果と分ける。
