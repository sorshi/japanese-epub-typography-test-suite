# Japanese EPUB Typography Test Suite

**日本語** / [English](README.en.md)

日本語縦書き組版テスト（EPUB 3、v1／初回リリース）。

日本語EPUBリーダーの縦書き、ルビ、禁則、縦中横、圏点、挿絵、ページ境界などを、同じ本文と条件で比較するためのリフローEPUBテスト集です。JLReq・CSS・Unicodeの一次資料を参照し、各試験にケースIDと期待結果を収録しています。検証本文は全33章（第1章〜第33章）で、表紙と奥付を収録しています。制作・発行はsorshi。ソースとビルド済みEPUBをMIT Licenseで提供します。

## EPUBの入手

公開版のEPUBは、GitHubリポジトリのReleasesから、添付ファイル`japanese-epub-typography-test-suite.epub`をダウンロードして利用します。Releaseごとの版と変更内容を確認してください。

GitHubが提供する`Source code (zip)`と`Source code (tar.gz)`は、そのReleaseのタグに対応するソース一式です。EPUBを作る場合は、展開したディレクトリで下記のビルド手順を実行します。

## テスト内容

第1〜24章は基本機能と総合サンプル、第25章は利用方法・判定基準、第26〜33章は境界条件と回帰試験です。各ケースのIDを使い、期待結果、参照資料、表示条件とともに結果を記録できます。

| 章 | 検証内容 |
| --- | --- |
| 1・2 | 縦書きの基本表示とCSS表現 |
| 3 | モノルビ、グループルビ、親文字ごとのルビの対応 |
| 4・5 | 句読点のぶら下げ。`none`・`allow-end`・`force-end`と行端の比較 |
| 6・7 | 半角・全角文字の縦中横 |
| 8・9 | 日本語・英語の均等割付 |
| 10 | 大きさの異なる文字と縦書きの中央線 |
| 11〜13 | 圏点の位置・色とルビの併用 |

| 16 | 同じ文字列・行長での`loose`・`normal`・`strict`の比較 |
| 17〜20 | 文字の向き、リストマーカー、縦横の書字方向の混在、文字の配置 |
| 21・22 | 連続ダッシュ（U+2014）、くの字点、繰返し記号の接続と分離禁止 |

## 表紙・奥付

表紙は読み順の先頭、奥付は巻末に配置し、目次からも移動できます。奥付には制作名、作成日、版、参照資料、ライセンスの適用範囲とMIT License全文を収録しています。OPFにも作者・発行者、権利情報、書籍一覧用の表紙画像を設定しています。

表紙原稿はSVGです。背景色、文字、短い横棒で構成し、外部画像やフォントファイルを埋め込んでいません。SVGの見た目は表示環境のフォントに依存します。EPUBには画像化した`EPUB/cover.png`を収録し、表紙と奥付に専用のCSSを使います。

## 画像テスト（第23章）

PNGとJPEGの挿絵を、透明度、背景色、図形の色、細線、白地と墨の比率を変えて比較します。「基準表示」は画像補正や背景へのなじませを適用しない表示を指します。章内のCSSには色変換や乗算を指定していません。

| ケース | 画像 | 基準表示で確認すること |
| --- | --- | --- |
| I23-01 | 透明背景のモノクロPNG | 透明部分にページ背景が見える |
| I23-02・03 | 白背景のモノクロPNG・JPEG | 不透明な白背景と図形の対応。JPEGの圧縮差 |
| I23-04・05 | 白背景のカラーPNG・JPEG | 青・赤・緑・黒の識別と形式による差 |
| I23-06 | 灰色背景のモノクロPNG | RGB各230の背景と図形の濃淡 |
| I23-07 | 端まで黒く、中央に白地約20.1％ | 中央の白い四角形の大きさ |
| I23-08 | 端まで黒く、中央に白地約5.3％ | 小さい白い四角形の見え方 |
| I23-09 | 白地に墨約0.293％の細線 | 幅54・高さ2ピクセルの線と縮小時の見え方 |
| I23-10 | 白地に墨約1.085％の直線 | 幅100・高さ4ピクセルの線との比較 |
| I23-11 | 白一色のPNG | 不透明な白い正方形。読み込み失敗との区別 |

リーダーで選べる明るい背景、色付きの背景、暗い背景で比較し、画像補正や色反転、背景へのなじませを使用した場合は設定を記録します。補正を無効にできない場合は、その条件を明記します。自動補正の有無や適用範囲を、すべてのリーダー共通の合否条件にはしません。

白地と墨の比率は元画像の画素数に対する割合です。画面の解像度や表示倍率とは区別します。画像の拡大・縮小、文字サイズ・画面寸法の変更、ページ移動も行い、縦横比、欠落・切れ、細線の見え方を確認します。

画像はすべて192×192ピクセルです。直線・矩形・三角形・四角形だけを整数座標で描き、外部素材・フォントを使いません。PNGはPython標準ライブラリで生成し、JPEGは同じPNGをImageMagickで変換しています。通常のEPUBビルドは収録済み画像を使うため、ImageMagickは不要です。

画像を再生成する場合だけImageMagickの`magick`コマンドが必要です。

```bash
python3 -B generate_image_fixtures.py
```

JPEGのバイト列はImageMagickやJPEGエンコーダーの版によって変わる場合があります。表示判定は実際に配布する画像で確認してください。

## ビルド

Python 3.9以降。ソースのルートディレクトリで次を実行します。

```bash
python3 build.py
```

出力: `dist/japanese-epub-typography-test-suite.epub`

別のファイル名・パスも指定できます。

```bash
python3 build.py --output /tmp/test.epub
```

GitHub以外での配布など、EPUBとソースZIPをまとめて作成する場合:

```bash
python3 build.py --source-zip dist/japanese-epub-typography-test-suite-source.zip
```

ソースZIPには本文・CSS・メタデータ・画像・表紙原稿・奥付・ライセンス・日本語／英語のREADME・`.gitignore`・ビルド／検証／画像生成スクリプトを収録します。`dist/`、キャッシュ、ローカルの検証ログは含めません。

ビルド時にXML構文、manifestの収録、表紙・本文・奥付の読み順と目次の一致、奥付のライセンス全文、ローカルリンクとフラグメント、IDの重複、Unicode試験文字列を確認します。ZIP内の日時を固定しているため、同じソースと同じ圧縮実装から同じアーカイブを生成できます。

回帰検証:

```bash
python3 -B -m unittest -v test_build.py
```

## EPUBCheckによる検証

[EPUBCheck公式リリース](https://github.com/w3c/epubcheck/releases)から配布ZIPを取得して展開します。

公式配布物の `epubcheck.jar` と依存ライブラリを同じ配布ディレクトリ構成のまま配置したうえで、次を実行します。

```bash
python3 build.py --epubcheck /path/to/epubcheck/epubcheck.jar
```

`--epubcheck` を省略してもビルドできます。その場合、EPUBCheckによる検証は**実行されません**。
EPUBCheck のエラーは終了コードとして伝播します。Javaが必要です。
`--source-zip`を併用すると、EPUBCheckが成功した後にソースZIPを作成します。

## 表示の判定

第25章に判定方法を収録しています。各ケースのID、期待結果、参照資料と合わせて使用してください。

- 「CSS」「組版方針」「対応状況・観察」を区別します。仕様が認める改行位置・字形の差を一律に不適合としません。
- 第23章は原画像の基準表示と、背景色や画像補正の設定による変化を分けて記録します。
- 結果は「適合」「不適合」「機能未対応」「フォント不足」「条件未成立」「未実施」で記録します。
- リーダー／OS／ブラウザの版、実際の使用フォント、表示領域、文字サイズ、実効行間、ページ方式を記録します。
- 禁則の「改行を許容する」は必ずその位置で改行するという意味ではありません。対象文字が境界へ来ていない場合も区別します。
- 試験枠の行長は`inline-size`で指定します。縦書きでは高さに対応します。枠には内側の余白があるため、ぶら下げは罫線ではなく内容領域の端を基準にします。
- 第29章はページ数を固定しません。P001〜P048が順番に一度ずつ現れ、再レイアウトと前後移動で欠落・重複しないことを確認します。
- 機能試験に`!important`を付けてリーダーの設定を強制上書きしません。書籍の指定と実効CSSが違う場合は記録します。
- 通常の行間での不具合と、意図的に狭い行間を与えたストレス試験を分けます。
- JavaScript、外部フォント、外部画像を使わずに試験本文を読めます。参照資料のリンクを開く場合だけ通信が必要です。
